A program that writes one original one-line office joke to /output/entry.txt for make.fun's "One-Line Office Joke Laugh-Off" bounty — a single line, under 200 characters, judged pairwise by a comedy-club judge on whether it really is a one-line office joke, how sharp its punchline is, how instantly it lands, how fresh it is, and how tight the wording is.

## Run it

```sh
node main.ts
```
